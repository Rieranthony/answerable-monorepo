Direct dependencies removed: `motion`, `shiki`, `clsx`, `tailwind-merge` (with F4), `next-themes` (with F7) and `shadcn` (F2) from `apps/web`, `cn` from `packages/ui`, and `@paper-design/shaders-react` if F10 goes ahead.

**The five changes that matter most.**

1. **F9 and F10, the hero mosaic.** On the live site, in a hidden tab, three fresh loads committed a 300×150 frame as the hero photo (the shader canvas reaches 1152×1728 only afterwards), so the photo shows as a letterboxed band for the life of the page. `probe()` accepts any non-uniform canvas of any size. The runtime WebGL dither exists to serve a light/dark difference the dark-only site no longer has; a baked frame measures 136 KB lossless WebP against 140 KB today. F9 is the four-line fix; F10 is the 261-line removal and needs the owner's eyes.
2. **F7, forced dark that is not dark.** `ThemeProvider` forces dark but keeps `defaultTheme="system"`, and next-themes' `resolvedTheme` is the OS scheme, not the forced one. Measured: a light-OS visitor gets the light dither settings on a dark page (3 tone levels against 4). The fix is the static `<html class="dark">` that ID already uses, and it deletes a client component, a dependency and a settings branch.
3. **F3, 209 lines of `packages/ui` no app imports**: both brand-logo components, `Textarea`, the combobox chips family, `InputGroupText`, `InputGroupTextarea`, `FieldDescription`, `ComboboxClear`.
4. **F4, the vendored dither kit** (335 lines) used for one wash with one colour, one direction and one opacity; no registry sync exists to protect, so it collapses to about 45 lines.
5. **F20, the one unsafe finding**: every flag image loads from `cdn.jsdelivr.net/gh/hampusborgos/country-flags@main`, a moving branch of a third-party repository. Also worth a look: F21, where every API page's Markdown points agents at an ID URL that is off in production by default.

**F4, the replacement (about 45 lines).** Same maths as `paintGradient` for the one used branch (`to` transparent, direction up):

```tsx
"use client"
const BAYER4 = [[0,8,2,10],[12,4,14,6],[3,11,1,9],[15,7,13,5]].map((r) => r.map((v) => (v + 0.5) / 16))
export function DitherWash({ opacity, className }: { opacity: number; className?: string }) {
  const ref = useRef<HTMLCanvasElement>(null)
  useEffect(() => { const c = ref.current!; const paint = () => paintWash(c, opacity); paint(); const ro = new ResizeObserver(paint); ro.observe(c); return () => ro.disconnect() }, [opacity])
  return <canvas ref={ref} aria-hidden className={cn("pointer-events-none absolute inset-0 h-full w-full", className)} style={{ imageRendering: "pixelated" }} />
}
// paintWash: cols = clamp(round(w / 3), 4, 960), rows likewise (max 600); density = (y + 0.5) / rows;
// lit = density > BAYER4[y & 3][x & 3]; alpha = (lit ? 0.35 + 0.65 * density : 0.12 * density) * opacity; fillRect white.
```
